# Управляемые информационные страницы

Администратор может менять содержимое через раздел «Страницы» (`/admin/pages`). Поле slug должно совпадать с адресом:

| Адрес     | slug     | Содержимое                                          |
| --------- | -------- | --------------------------------------------------- |
| /policy   | policy   | Утверждённая политика обработки персональных данных |
| /donation | donation | Реальные реквизиты и согласованный порядок помощи   |
| /kontakty | kontakty | Проверенные контакты и время работы                 |

Публичный frontend читает существующий `/api/v1/pages/{slug}`. Текст проходит штатную серверную очистку HTML при сохранении в CMS. Контактная форма и ссылка для обсуждения помощи сохраняются рядом с управляемым содержимым.

Если записи нет (404) или тело пустое, остаётся прежняя явная заглушка. При недоступности API показывается ошибка загрузки вместо ложного сообщения об отсутствии документа. Обычное кеширование публичного API использует revalidate 60 секунд.

Техническое подключение не создаёт и не утверждает юридический текст, реквизиты или контакты. Перед публичным использованием форм администратору необходимо внести проверенное содержимое.

## Что подготовить владельцу

- Для `policy`: утверждённый полный текст, сведения об операторе, контакт для обращений и дата/версия документа. Содержимое должно соответствовать используемой в формах версии согласия; изменение текста не заменяет проверку этого соответствия.
- Для `kontakty`: публичные телефон и e-mail, адрес при наличии, ссылки на официальные каналы, часы работы и часовой пояс.
- Для `donation`: проверенные данные получателя, банковские реквизиты, валюта и согласованный порядок помощи. Платёжные данные должны быть проверены владельцем до публикации.

Перед публикацией проверить ссылки и контакты, убрать условные значения и открыть каждую страницу на телефоне. Секреты, пароли и токены в CMS не вносятся.

## Публичные страницы без JavaScript

Основной текст, первая страница календаря и нужд, а также ссылки навигации доступны без JavaScript. В этом режиме показывается подсказка; формы, вход, запись и догрузка списков требуют JavaScript. Контактные поля заблокированы до подключения обработчиков формы, чтобы браузер не отправил введённые данные обычным GET-запросом.
