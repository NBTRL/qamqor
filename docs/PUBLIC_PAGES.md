# Управляемые информационные страницы

Администратор может менять содержимое через раздел «Страницы» (`/admin/pages`). Поле slug должно совпадать с адресом:

| Адрес     | slug     | Содержимое                                          |
| --------- | -------- | --------------------------------------------------- |
| /policy   | policy   | Утверждённая политика обработки персональных данных |
| /donation | donation | Реальные реквизиты и согласованный порядок помощи   |
| /kontakty | kontakty | Проверенные контакты и время работы                 |

Публичный frontend читает существующий `/api/v1/pages/{slug}`. Текст проходит штатную серверную очистку HTML при сохранении в CMS. Контактная форма и ссылка для обсуждения помощи сохраняются рядом с управляемым содержимым.

Если записи нет (404) или тело пустое, остаётся прежняя явная заглушка. При недоступности API показывается ошибка загрузки вместо ложного сообщения об отсутствии документа. Обычное кеширование публичного API использует revalidate 60 секунд.

Техническое подключение не создаёт и не утверждает юридический текст, реквизиты или контакты. Перед публичным использованием форм администратору необходимо внести проверенное содержимое.
